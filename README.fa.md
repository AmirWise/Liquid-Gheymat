یک ردیاب تمیز و مدرن برای قیمت ارز، کریپتو و فلزات با رابط شیشه‌ای مایع، بروزرسانی سریع و ابزارهای کاربردی برای استفاده روزمره.

> **توجه:** همه‌ی بخش‌های زیر مربوط به کد قدیمی (نسخه ۴.۰.۰) است. برای نسخه‌ی فعلی (۵.۰.۰ به بعد) به [Gheymat Morabba](https://github.com/AmirWise/GheymatMorabba) مراجعه کنید.

## ✨ تغییرات نسخه ۴.۰.۰

- بروزرسانی بسیار سریع‌تر رابط کاربری (استفاده مجدد از کارت‌ها)
- مدیریت کامل پورتفولیو (افزودن/حذف، مرتب‌سازی با کشیدن)
- انتخابگر ارز با قابلیت جستجو
- بخش مرور بازار (بیشترین رشد و بیشترین افت)
- شروع فوری برنامه با استفاده از کش محلی
- سیستم بروزرسانی خودکار بهبودیافته
- خروجی به CSV و کپی به کلیپ‌بورد
- پنل تنظیمات (فاصله بروزرسانی، هشدار قیمت، اعلان‌ها، مدیریت کش)
- لایه API مقاوم‌تر (تلاش مجدد، مدار شکن، کش موقت)
- پشتیبانی از ویجت‌های دسکتاپ و حالت فشرده
- نمایش اسپارک‌لاین تاریخچه قیمت و ابزار تبدیل سریع

> این مستندات با کد قدیمی برنامه (نسخه ۴.۰.۰) همخوانی دارد.

## 🚀 راه‌اندازی سریع

### پیش‌نیازها
- ویندوز ۱۰ (بیلد ۱۹۰۳ به بالا) یا ویندوز ۱۱ (توصیه می‌شود)
- پایتون ۳.۸ یا جدیدتر

### نصب
```bash
git clone https://github.com/AmirWise/GheymatMorabba.git
cd Gheymat-Morabba
pip install -r requirements.txt
python main.py
```

### نکات
- در اولین اجرا برنامه بلافاصله از کش محلی بارگذاری می‌شود و سپس داده‌های زنده را در پس‌زمینه دریافت می‌کند.
- ویجت‌های دسکتاپ فقط در ویندوز کار می‌کنند.
